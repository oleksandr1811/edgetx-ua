# Українська озвучка для EdgeTX

Українські голосові підказки для пультів на EdgeTX: режими польоту, телеметрія, стан акумулятора, шасі та закрилки, таймери, числа й одиниці виміру.

## Чим це відрізняється

Озвучку зроблено якісно, а не через гугл-перекладач. Кожну фразу перевірено й виправлено вручну: правильні відмінки та рід числівників («одна», «дві»), коректні форми одиниць («вольт», «вольта», «вольтів»), виправлені помилки й невдалі переклади. 

## Як встановити

1. Вимкни пульт і підключи SD-карту до комп'ютера (або увімкни пульт у режимі USB-накопичувача).
2. На SD-карті відкрий папку `SOUNDS -> en`.
3. Скопіюй у `SOUNDS/en/` усі файли `.wav` з цього репозиторію(якщо скаже що файл вже існує нажми перезаписати).
4. Безпечно від'єднай SD-карту й увімкни пульт.
